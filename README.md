# Task Tracker

Личный трекер задач для руководителя ИИ-проектов. Работает прямо в браузере, без серверов и регистрации.

## Что умеет

- Создавать, редактировать и удалять задачи
- У задачи есть название, описание, срок, приоритет, статус, проект и направление (продажи, маркетинг, финансы и т.д.)
- Два вида: **список** и **канбан-доска** («К выполнению → В работе → Готово»), между ними есть переключатель
- Поиск, фильтры, сортировка по сроку и приоритету
- Подсветка просроченных задач и задач на сегодня
- Списки направлений и проектов можно менять в настройках
- Светлая и тёмная тема
- Удобно пользоваться с телефона
- Резервная копия: скачать все задачи в файл и загрузить обратно

## Где хранятся задачи

Задачи хранятся **в памяти вашего браузера** (localStorage). Это значит:

- задачи видны только в том браузере и на том устройстве, где вы их создали;
- если очистить данные браузера (историю, cookies, данные сайтов), задачи пропадут;
- поэтому периодически нажимайте **«Скачать резервную копию»** и сохраняйте файл.

## Как открыть

**По ссылке:** https://campusateam.github.io/task-tracker/ (работает и с телефона).

**На своём компьютере:** откройте файл `index.html` двойным щелчком, он откроется в браузере.

> Задачи, созданные по ссылке и в локальном файле, хранятся отдельно: для браузера это два разных сайта.

## Как обновить версию по ссылке

Сайт публикуется через GitHub Pages из ветки `main`. После изменений в файлах:

```bash
git add -A
git commit -m "Описание изменений"
git push
```

Через 1–2 минуты новая версия появится по ссылке. Задачи при этом не пропадут: они хранятся в браузере, а не в репозитории.

## Файлы проекта

| Файл | Что это |
|---|---|
| `index.html` | Страница приложения (каркас) |
| `style.css` | Внешний вид: цвета, шрифты, расположение |
| `app.js` | Логика: задачи, фильтры, сохранение |
| `SPEC.md` | Подробное описание: что и как должно работать |
| `CLAUDE.md` | Правила для ИИ-помощника, который пишет код |
