# SPEC: Task Tracker

## 1. Цель

Простой личный трекер для реальных рабочих задач руководителя ИИ-проектов. Задачи можно разложить по проектам и направлениям бизнеса, видеть сроки и приоритеты и вести их по этапам.

## 2. Пользователи

- Один пользователь: владелец трекера.
- Работа с компьютера и с телефона через браузер.
- Регистрации и входа нет.

## 3. Функции

### 3.1 Задачи
- Создать задачу. Обязательно только название.
- Отредактировать любое поле.
- Удалить задачу с подтверждением («Точно удалить?»).
- Быстро сменить статус: в списке выпадающим меню, на доске перетаскиванием.

### 3.2 Поля задачи
| Поле | Обязательно | Значения |
|---|---|---|
| Название | да | текст |
| Описание | нет | многострочный текст |
| Срок | нет | дата |
| Приоритет | да (по умолчанию «Средний») | Высокий / Средний / Низкий |
| Статус | да (по умолчанию «К выполнению») | К выполнению / В работе / Готово |
| Проект | нет | из списка проектов |
| Направление | нет | из списка направлений |

### 3.3 Два вида отображения
- **Список**: задачи строками, видны все основные поля.
- **Канбан-доска**: три колонки по статусам, карточки перетаскиваются мышкой. На телефоне вместо перетаскивания используется меню смены статуса.
- Переключатель видов виден всегда. Последний выбранный вид запоминается.

### 3.4 Поиск, фильтры, сортировка
- Поиск по названию и описанию.
- Фильтры: направление, проект, приоритет, статус. Кнопка «Сбросить фильтры».
- Сортировка: по сроку (ближайшие сверху, без срока в конце) или по приоритету.
- Поиск и фильтры работают в обоих видах.
- В фильтрах направления и проекта есть вариант «Без направления» / «Без проекта».
- В виде «Список» выполненные задачи показываются в конце.
- Выбранная сортировка запоминается, фильтры и поиск — нет (сбрасываются при перезагрузке).

### 3.5 Подсветка сроков
- **Просрочено**: срок прошёл, задача не в статусе «Готово». Красная метка.
- **Сегодня**: срок сегодня. Оранжевая метка.
- Задачи «Готово» не подсвечиваются.

### 3.6 Настройки
- Редактируемые списки **направлений** и **проектов**: добавить, переименовать, удалить.
- Начальные направления: Продажи, Маркетинг, Финансы, Образование.
- Начальные проекты: «Проект 1» (пример).
- При удалении направления или проекта, которое используется в задачах, приложение предупреждает. Задачи не удаляются, у них просто становится «Без направления» / «Без проекта».
- Тема: светлая / тёмная / как в системе.

### 3.7 Резервная копия
- «Скачать резервную копию» сохраняет все данные в файл `task-tracker-backup-ГГГГ-ММ-ДД.json`.
- «Загрузить из файла» восстанавливает данные из такого файла, предварительно предупредив, что текущие данные будут заменены.

## 4. Ограничения

- Только HTML, CSS и чистый JavaScript. Без React и других фреймворков, без сборщиков.
- Без базы данных и сервера. Данные хранятся только в localStorage браузера.
- Без внешних API и сторонних библиотек (включая CDN).
- Интерфейс на русском языке.
- Приложение работает, если просто открыть `index.html`, и при размещении на GitHub Pages / Netlify.
- Данные не синхронизируются между устройствами. Это осознанное ограничение.

## 5. Структура данных

Всё хранится в localStorage под одним ключом `taskTracker.v1` в виде JSON:

```json
{
  "version": 1,
  "tasks": [
    {
      "id": "t_1730800000000_ab12",
      "title": "Подготовить отчёт по пилоту",
      "description": "Собрать метрики за октябрь",
      "dueDate": "2026-11-10",
      "priority": "high",
      "status": "in_progress",
      "projectId": "p_1",
      "directionId": "d_finance",
      "createdAt": "2026-11-05T10:00:00.000Z",
      "updatedAt": "2026-11-05T10:00:00.000Z"
    }
  ],
  "directions": [
    { "id": "d_sales", "name": "Продажи" },
    { "id": "d_marketing", "name": "Маркетинг" },
    { "id": "d_finance", "name": "Финансы" },
    { "id": "d_education", "name": "Образование" }
  ],
  "projects": [
    { "id": "p_1", "name": "Проект 1" }
  ],
  "settings": {
    "view": "list",
    "theme": "system",
    "sort": "dueDate"
  }
}
```

Допустимые значения:
- `priority`: `high` | `medium` | `low`
- `status`: `todo` | `in_progress` | `done`
- `dueDate`: строка `ГГГГ-ММ-ДД` или `null`
- `projectId`, `directionId`: id из списков или `null`
- `view`: `list` | `board`; `theme`: `light` | `dark` | `system`; `sort`: `dueDate` | `priority`

## 6. Критерии готовности

Приложение готово, когда:

1. Открывается двойным щелчком по `index.html` без ошибок.
2. Можно создать, отредактировать и удалить задачу со всеми полями.
3. После перезагрузки страницы все задачи и настройки на месте.
4. Переключатель «Список / Доска» работает, на доске можно перетащить карточку в другую колонку и статус меняется.
5. Поиск, все 4 фильтра и обе сортировки работают и в списке, и на доске.
6. Просроченные задачи и задачи на сегодня подсвечены, выполненные нет.
7. В настройках можно добавить, переименовать и удалить направление и проект, задачи при этом не теряются.
8. Тёмная тема включается и запоминается.
9. На экране телефона (ширина 375px) всё читается, кнопки нажимаются, нет горизонтальной прокрутки.
10. Резервная копия скачивается в файл и успешно загружается обратно.
11. Приложение открывается по ссылке после размещения на GitHub Pages или Netlify.
